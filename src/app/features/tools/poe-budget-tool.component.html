Adds up each device's power by PoE class (or watts you enter) and compares it with the switch's total PoE budget. "What the switch reserves" is the power the switch must supply per port (covers cable loss) and is the safer number for switches that reserve by class. "Device's max draw" is what the device itself can use, for switches that allocate by actual draw.

IEEE 802.3af / at / bt class limits (switch / device): Class 0 15.4 / 13 W, 1 4 / 3.84 W, 2 7 / 6.49 W, 3 15.4 / 13 W (802.3af); 4 30 / 25.5 W (802.3at); 5 45 / 40 W, 6 60 / 51 W (802.3bt Type 3); 7 75 / 62 W, 8 90 / 71.3 W (802.3bt Type 4). Some 802.3bt switches reserve slightly less for classes 2 and 3. Check the switch's per-port limit too.
